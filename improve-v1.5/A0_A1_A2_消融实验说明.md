# A0 / A1 / A2 消融实验使用说明

本目录已经准备好 A0、A1、A2 三组消融配置与批量运行脚本。

## 1) 三组实验对应关系

1. `A0`: `configs/model_configs/ablation_a0_dynpillar_baseline.yaml`
2. `A1`: `configs/model_configs/ablation_a1_radar7pillar.yaml`
3. `A2`: `configs/model_configs/ablation_a2_radar7pillar_vel.yaml`

## 2) 专用脚本（推荐）

脚本：`scripts/run_ablation_a0_a2.ps1`

### 仅查看计划（不训练）

```powershell
cd E:\毕设\code\4d-radar\improve-v1.5
python -m pcdet_ext.utils.ablation_runner --root . --preset a0_a2 --list
.\scripts\run_ablation_a0_a2.ps1 -DryRun
```

### 正式训练并评估 A0/A1/A2

```powershell
.\scripts\run_ablation_a0_a2.ps1 -RunTrain -Workers 4
```

可选限制 epoch（快速试跑）：

```powershell
.\scripts\run_ablation_a0_a2.ps1 -RunTrain -Workers 4 -Epochs 5
```

## 3) 通用脚本方式

脚本：`scripts/run_ablation_suite.ps1` 也已支持筛选：

```powershell
.\scripts\run_ablation_suite.ps1 -Preset a0_a2 -RunTrain -Workers 4
```

或按 id 明确指定：

```powershell
.\scripts\run_ablation_suite.ps1 -ExpIds A0,A1,A2 -RunTrain -Workers 4
```

## 4) 输出结果

专用脚本默认输出到：

- `outputs/ablations/a0_a2/ablation_summary.csv`
- `outputs/ablations/a0_a2/ablation_summary.md`
- `outputs/ablations/a0_a2/A0.json`
- `outputs/ablations/a0_a2/A1.json`
- `outputs/ablations/a0_a2/A2.json`

如果你使用通用脚本，则按 `-OutputDir` 指定目录。

## 5) 注意事项

1. `A0` 使用 `DynPillarVFE`，通常需要环境包含对应依赖（如 `torch-scatter`）。
2. 若你不加 `-RunTrain`，runner 会尝试读取已存在 checkpoint；不存在会报错。
3. 如需“缺 ckpt 时跳过并继续写汇总”，加 `-SkipMissingCkpt`。
